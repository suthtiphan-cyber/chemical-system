# SFC Chemical 3.0 (GitHub Pages Web Ready)

โฟลเดอร์นี้รวบรวมเฉพาะไฟล์เว็บที่จำเป็นสำหรับการอัปโหลดขึ้น GitHub Pages โดยตรง:
- `index.html` (หน้าเว็บหลัก)
- `migrate.html` (เครื่องมือเชื่อมต่อและโอนถ่ายข้อมูล)
- `initial-data.json` (ข้อมูลเริ่มต้น)
- `css/` (สไตล์และชุดตกแต่ง UI)
- `js/` (ระบบจัดการฐานข้อมูล Firebase Firestore, การเข้าสู่ระบบ และการประมวลผล)
- `picture/` (โลโก้และรูปภาพ)
- `.nojekyll` (ไฟล์พิเศษเพื่อป้องกันระบบ Jekyll บน GitHub ข้ามการอ่านไฟล์)
